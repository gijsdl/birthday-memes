# Birthday memes

## Overview

Dit project is ontstaan doordat mijn zus en ik elk jaar meer en meer memes sturen tijdens onze verjaardagen. 
Het uitzoeken van fotos is daardoor een stuk lastiger geworden. Vandaar deze applicatie.  
Het doel van deze applicatie is sorteren van fotos makkelijker te maken.
Je kan foto's categoriseren in categorieën die je zelf maakt.

## setup

Maak in de image folder de volgende twee folders aan: img-old en img-new.  
Importeer de database.

## Werking

Vul de img-new folder aan met foto's die je denkt nog niet te hebben. Je krijgt op je scherm telkens maar één van deze foto's aan de rechterkant te zien.
In het midden zie je de foto's die je al hebt. Deze staan in de img-old folder (**Let Op:** zet hier zelf geen foto's in). 
Aan de linkerkant zie je de categorieën die je hebt gemaakt. Als je op één van deze klikt, zie je alleen de foto's uit die categorie. Dit helpt met het uitzoeken.  
Als je de foto nog niet hebt kan je op toevoegen drukken. Deze wordt dan in de img-old folder gezet met een verwijzing in de database.
Als je hem al wel hebt kan je op verwijderen drukken. Dan wordt deze foto verwijderd.
